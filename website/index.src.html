Semua komputer lab & kantor, dalam genggaman.

AruniControl menampilkan layar semua komputer dalam satu grid. Kunci layar, kirim pesan, tampilkan layar guru, atau ambil alih mouse & keyboard — dari PC, Mac, atau HP. Bahkan lewat paket data, tanpa VPN.

Panduan lengkap

Cara memasang & memakai

Pilih perangkat Anda. Setiap langkah dilengkapi gambar. Klik gambar untuk memperbesar.

1Instal

Jalankan installer

  1. Unduh AruniControl-Setup-…-Windows-x64.exe dari bagian Unduh.
  2. Klik dua kali file tersebut, lalu pilih Yes saat Windows meminta izin administrator.
  3. Jika muncul layar biru “Windows protected your PC”, klik More info → Run anyway. Ini normal karena installer belum ditandatangani sertifikat berbayar.
  4. Klik Install. Installer otomatis mendaftarkan layanan AruniControl dan membuka firewall untuk port 11100.
  5. Setelah selesai, AruniControl Configurator terbuka otomatis.

Lakukan langkah ini di setiap komputer, termasuk komputer guru. Untuk banyak komputer sekaligus, installer bisa dijalankan senyap: AruniControl-Setup-….exe /S. Dengan kode pemasangan, kunci akses ikut terpasang otomatis.

2Layanan

Pastikan layanan berjalan

Di Configurator buka halaman Service. Status harus Running. Jika belum, klik Start service.

Layanan ini yang membuat komputer bisa dipantau. Ia berjalan otomatis setiap kali Windows menyala, juga sebelum ada yang login.

3Kunci

Pasang kunci akses

Komputer hanya menuruti perintah dari Master yang memegang kunci yang cocok. Ikuti tab Kunci akses. Cukup sekali untuk satu sekolah atau kantor.

4Master

Buka AruniControl Master di komputer guru

  1. Start menu → AruniControl → AruniControl Master.
  2. Komputer di jaringan yang sama ditemukan otomatis (Network discovery) dan tampil sebagai thumbnail.
  3. Pilih satu, beberapa, atau semua komputer, lalu pakai tombol di toolbar: Monitoring, Demo, Lock, Remote view/control, Text message, Power on/off, dan lainnya.
  4. Ingin mengelompokkan per ruangan? Lihat langkah 5.
5Ruangan

Kelompokkan per ruangan (opsional)

  1. Di Configurator → General, ubah Network object directory → Backend menjadi Builtin (computers and locations in local configuration).
  2. Buka Locations & computers. Klik + di bawah daftar Locations untuk membuat ruangan (mis. Lab Komputer 1).
  3. Pilih ruangan itu, lalu klik + di bawah Computers dan isi nama, alamat IP/hostname, dan (opsional) MAC address untuk fitur Power on.
  4. Klik Apply. Di Master, buka panel Locations & computers (kiri bawah) untuk memilih ruangan.
1Instal

Pindahkan ke Applications

  1. Unduh AruniControl-…-macOS-arm64.zip, lalu klik dua kali untuk mengekstrak.
  2. Seret AruniControl.app ke folder Applications.
  3. Buka aplikasinya. Jika macOS menolak (“cannot be opened because the developer cannot be verified”), buka System Settings → Privacy & Security, gulir ke bawah, lalu klik Open Anyway.

Cara cepat lewat Terminal: xattr -dr com.apple.quarantine /Applications/AruniControl.app

Tidak perlu password admin. Semua pengaturan tersimpan per pengguna.

2Aplikasi

Master & Configurator

  • AruniControl.app membuka Master (untuk memantau komputer lain).
  • Configurator ada di dalam paket aplikasi: klik kanan AruniControl.app → Show Package Contents → Contents → MacOS → klik dua kali veyon-configurator.
    Atau lewat Terminal: /Applications/AruniControl.app/Contents/MacOS/veyon-configurator
3Agar Mac bisa dipantau

Nyalakan layanan & beri 2 izin

  1. Di Configurator buka Service, lalu klik Start service. Layanan jalan otomatis setiap login (LaunchAgent, tanpa admin).
  2. Buka System Settings → Privacy & Security → Screen Recording. Klik +, tekan ⌘⇧G, ketik /Applications/AruniControl.app/Contents/MacOS/veyon-server, lalu nyalakan.
  3. Ulangi di Accessibility untuk file yang sama. Izin ini yang membuat klik & ketikan dari Master/HP bisa masuk.
  4. Kembali ke Configurator → Service → Stop service lalu Start service agar izin baru terbaca.

Layar hitam? Izin Screen Recording belum aktif. Bisa lihat tapi tidak bisa klik? Izin Accessibility belum aktif. Setelah mengubah izin, selalu restart layanan.

4Kunci

Pasang kunci akses

Sama seperti di Windows: ikuti tab Kunci akses. Mac dan Windows bisa saling memantau selama kuncinya sama.

1Instal

Pasang APK

  1. Buka halaman ini di HP, lalu ketuk Unduh APK.
  2. Setelah selesai, ketuk file AruniControl-…-Android-arm64.apk.
  3. Jika muncul “Untuk keamanan, HP Anda tidak diizinkan menginstal aplikasi tidak dikenal”, ketuk Setelan → aktifkan Izinkan dari sumber ini → kembali → Instal.
  4. Jika Play Protect memberi peringatan, pilih Detail lainnya → Tetap instal.
2Akses

Hubungkan akses

Ketuk Mulai, lalu pilih salah satu cara berikut:

  • Punya kode QR Aruni Gateway? Ini paling mudah. Sekali pindai, lokasi dan kunci akses terpasang otomatis dan bisa dipakai dari mana saja. Lihat Akses jarak jauh.
  • Kunci akses: pilih file …_private_key.pem yang diekspor dari Configurator (tab Kunci akses, langkah 4). Nama kunci harus sama persis dengan nama di komputer.
  • Akun komputer: nama pengguna & kata sandi yang terdaftar di komputer siswa, jika sekolah memakai metode login.

Kunci dan kata sandi hanya disimpan di HP ini dan tidak pernah dikirim ke internet.

3Pantau

Semua komputer dalam satu grid

  • Jika HP satu Wi-Fi dengan komputer, komputer ditemukan otomatis. Ketuk ↻ untuk memperbarui daftar.
  • Geser chip di atas untuk memilih ruangan. Pakai kotak cari untuk mencari nama komputer atau pengguna.
  • Titik warna menunjukkan status: ● online, ● sedang menghubungkan, ● kunci ditolak, ● mati.
  • Tombol bawah: Kunci, Buka, Pesan, dan Semua untuk seluruh aksi.
4Aksi

Satu ketuk untuk semua

Ketuk Semua untuk semua komputer yang tampil, atau tahan satu kartu untuk mulai memilih beberapa komputer lalu ketuk aksinya. Aksi yang tersedia:

  • Kelas: kunci/buka layar, kirim pesan, tangkap layar, buka website, jalankan aplikasi, kunci keyboard & mouse.
  • Demo & file: tampilkan layar siswa ke semua, hentikan demo, kirim file, kumpulkan file.
  • Pembatasan: blokir/buka internet, bisukan/nyalakan suara.
  • Daya & sesi: nyalakan (Wake-on-LAN), login pengguna, mulai ulang, matikan, keluarkan pengguna.
5Kendalikan

Lihat & kendalikan dari jauh

  • Ketuk satu kartu untuk membuka layar penuh. Mode Lihat hanya menonton.
  • Ketuk Kendalikan atau pilih Kontrol untuk mengambil alih: ketuk = klik, ketuk dua kali = klik ganda, tahan = klik kanan, geser satu jari = menyeret, dua jari = zoom & geser layar, strip di kanan = scroll.
  • Baris tombol di bawah: keyboard HP, Esc Tab Enter, serta pintasan seperti Ctrl+Alt+Del, Win, Alt+Tab, Alt+F4, Ctrl+C.
  • Ikon kamera menyimpan tangkapan layar ke HP.
6Pengaturan

Ruangan, tema & lainnya

Ketuk ikon ⚙ di kanan atas untuk:

  • Mengganti atau menghapus kunci akses.
  • Akses dari mana saja: Aruni Gateway, VPN WireGuard, ZeroTier.
  • Ruangan & komputer: menambah komputer lewat alamat IP dan mengelompokkannya.
  • Melihat file terkumpul & tangkapan layar, memilih tema terang/gelap, dan ukuran kartu.
7Baru di 1.4.0

Chat, bicara & pantau aplikasi

  • Chat: kirim pesan dan terima balasan dari pengguna komputer, tampil sebagai gelembung percakapan. Bila ada balasan saat chat tertutup, muncul banner dan tanda di kartu komputer.
  • Bicara (AruniVoice): tahan tombol besar untuk berbicara ke pengguna komputer, atau aktifkan Interkom dua arah. Izinkan mikrofon saat diminta. Gunakan headset agar tidak berdengung.
  • Aplikasi berjalan: lihat aplikasi yang sedang dibuka, aplikasi yang sedang dipakai ditandai paling atas, dan tutup aplikasi dari jauh (dengan konfirmasi).
  • Semuanya ada di menu ⋮ saat membuka satu komputer, dan di lembar Aksi ketika satu komputer dipilih.
8Bicara

Tahan untuk bicara

Suara Anda terdengar langsung di speaker komputer. Pengguna komputer membalas dengan menahan tombol di jendela AruniVoice yang muncul di layarnya. Indikator level menunjukkan suara kedua pihak.

Pembaruan aplikasi: bila ada versi baru, beranda menampilkan banner "Versi … tersedia". Ketuk Perbarui, aplikasi mengunduh dan memverifikasinya, lalu Android meminta konfirmasi pemasangan. Pertama kali, izinkan AruniControl memasang aplikasi.

1Konsep

Kenapa perlu kunci?

Agar tidak sembarang orang bisa mengendalikan komputer. Kunci terdiri dari dua bagian:

  • Kunci private: hanya dipegang komputer guru/admin (dan HP guru). Jangan dibagikan.
  • Kunci publik: dipasang di semua komputer yang dipantau.

Komputer hanya menerima perintah dari Master yang memegang kunci private pasangan dari kunci publiknya.

2Buat

Buat pasangan kunci (sekali saja)

  1. Di komputer guru/admin, buka Configurator → Authentication keys.
  2. Klik Create key pair dan beri nama, misalnya sekolah atau lab1.
  3. Klik Apply.
3Sebarkan

Pasang kunci publik di semua komputer

  1. Di komputer guru: pilih kunci bertipe public → Export key. Simpan file sekolah_public_key.pem ke flashdisk atau folder bersama.
  2. Di setiap komputer siswa: Configurator → Authentication keys → Import key → pilih file tadi → isi nama yang sama persis (sekolah) → Apply.

Lebih cepat: pakai kode pemasangan (tab Pemasangan), sehingga kunci terpasang saat instalasi tanpa impor manual. Cara lama lewat perintah: veyon-cli authkeys import sekolah/public sekolah_public_key.pem (di Windows: veyon-wcli.exe dari folder instalasi).

4HP guru

Kunci untuk aplikasi Android

Cara termudah: pakai Aruni Gateway dan pilih kunci di kolom “Give new phones this access key”. HP akan menerima kuncinya otomatis saat memindai QR. Lihat Akses jarak jauh.

Cara manual: di komputer guru pilih kunci bertipe private → Export key. Kirim file .pem ke HP (kabel USB, Drive, WhatsApp ke diri sendiri), lalu di aplikasi pilih Kunci akses → Pilih file kunci dan isi nama kunci yang sama.

Akses jarak jauh

Pakai paket data? Tetap bisa.

Aruni Gateway menghubungkan HP Anda ke semua komputer kantor lewat internet. Tidak perlu VPN, tidak perlu mengatur router atau port forwarding.

Data dienkripsi dari HP sampai PC gateway (X25519 + ChaCha20-Poly1305), sehingga relay tidak bisa membaca isinya. Gateway hanya meneruskan ke alamat jaringan lokal di port AruniControl.

1Di kantor

Aktifkan Aruni Gateway di satu PC

  1. Pilih satu PC yang selalu menyala dan terhubung ke jaringan kantor/lab. Boleh komputer guru, server, atau PC mana saja yang sudah terpasang AruniControl.
  2. Buka Configurator → Aruni Gateway.
  3. Centang Use this computer as Aruni Gateway, isi Location name (mis. Lab Komputer 1), lalu klik Apply.
  4. Tunggu sampai Status menjadi ● Online.
  5. Di Give new phones this access key, pilih kunci (mis. sekolah) agar HP langsung mendapat kunci akses.

Relay server bawaan sudah terisi. Biarkan saja kecuali Anda menjalankan relay sendiri.

2Di HP

Pindai kode QR

  1. Di Configurator klik Show pairing QR code. Kode berlaku sekali pakai selama 15 menit.
  2. Di aplikasi: ⚙ Pengaturan → Akses dari mana saja → Pindai kode QR, arahkan kamera ke layar. Bisa juga memakai kamera bawaan HP: link arunicontrol://pair… langsung membuka aplikasi.
  3. Selesai. Lokasi baru muncul sebagai ruangan dan semua komputer di kantor tampil, baik lewat Wi-Fi maupun paket data.

HP yang terhubung tercatat di Connected phones pada Configurator dan aksesnya bisa dicabut kapan saja dengan Remove access.

1Di gateway kantor

Salin kode pendaftaran laptop

  1. Di PC gateway buka Configurator → Aruni Gateway. Gateway harus sudah aktif, lihat bagian atas.
  2. Di bagian Laptops outside the office, klik Copy untuk menyalin kode pendaftaran (diawali ARUNIL1:).
  3. Kode ini bisa dipakai untuk banyak laptop sekaligus. Klik New code kalau kode sempat tersebar; laptop yang sudah terdaftar tetap jalan.

Tabel di bawahnya menampilkan semua laptop: Online, away (sedang di luar), In the office, atau Offline, beserta port-nya. Laptop yang hilang atau dijual cukup dipilih lalu klik Remove laptop.

2Di laptop

Aktifkan mode laptop jelajah

  1. Di laptop buka Configurator → Aruni Gateway.
  2. Di bagian This laptop outside the office, tempel kode pada Enrollment code, lalu centang Keep this laptop monitored outside the office.
  3. Tunggu sampai status menjadi ● Connected to "…".

Banyak laptop sekaligus? Pasang installer dengan AruniControl-Setup-….exe /S /ENROLL=ARUNIL1:…, atau di laptop yang sudah terpasang jalankan veyon-wcli gateway enroll ARUNIL1:… sebagai administrator. Di Mac: …/veyon-cli gateway enroll ARUNIL1:….

3Pantau

Lihat laptop dari HP atau Master kantor

  • Aplikasi HP (yang sudah dipasangkan dengan gateway): laptop yang sedang di luar muncul di ruangan "<lokasi> · Di luar kantor", lengkap dengan layar live, kontrol, kunci layar, dan pesan.
  • Master di kantor (backend Network discovery): muncul otomatis di lokasi "<lokasi> - outside the office". Dengan backend Builtin, tambahkan komputer dengan alamat IP-gateway:port (port ada di tabel langkah 1, mis. 192.168.1.10:11601).
  • Begitu laptop kembali ke kantor, ia tampil lagi seperti komputer biasa di jaringan lokal.

Selama di luar kantor, Demo (menampilkan layar guru ke laptop) dan Nyalakan (Wake-on-LAN) tidak bisa dipakai, karena laptop tidak bisa dijangkau langsung. Fitur lain tetap jalan: pantau, kendalikan, kunci layar, pesan, kirim file, dan blokir internet.

Pengguna laptop sebaiknya diberi tahu bahwa laptop kantor tetap dapat dipantau di luar jam dan lokasi kantor.

+Alternatif

Sudah punya VPN?

  • WireGuard / MikroTik (RouterOS 7): impor file .conf di Akses dari mana saja → VPN WireGuard. Hanya lalu lintas AruniControl yang lewat VPN, aplikasi lain tetap memakai internet biasa. Ketuk Cara membuat di MikroTik untuk panduan singkat.
  • ZeroTier: pasang ZeroTier One dari Play Store, gabung ke Network ID kantor, lalu minta admin menyetujui HP Anda.
  • Subnet tambahan: di Ruangan & komputer, tambahkan subnet (mis. 192.168.10.0/24) agar komputer di balik VPN ikut ditemukan.
Baru di 1.4.0

Lebih ringan untuk admin

Semua komputer memperbarui dirinya sendiri, admin langsung tahu saat ada masalah, dan setiap laptop punya catatan yang bisa diekspor ke Excel. Semuanya dalam Bahasa Indonesia.

1Pembaruan otomatis

Rilis sekali, semua komputer ikut

  • Layanan AruniControl di setiap PC Windows dan Mac memeriksa versi baru setiap 6 jam, mengunduhnya, mencocokkan checksum SHA-256, lalu memasangnya sendiri. Pengaturan, kunci, dan gateway tidak berubah.
  • Status dan tombol Periksa sekarang ada di Configurator → Pembaruan. Hilangkan centang bila ingin memperbarui secara manual.
  • Aplikasi Android memberi tahu bila ada versi baru dan memasangnya dengan satu ketukan.

Mac: mulai 1.4.0 aplikasi ditandatangani dengan identitas tetap, sehingga izin Screen Recording & Accessibility tidak hilang saat update. Hanya saat pindah dari 1.3.x ke 1.4.0 izin perlu diberikan sekali lagi.

2Notifikasi

Peringatan langsung ke Telegram

  1. Di Telegram, buka @BotFather, kirim /newbot, ikuti langkahnya, lalu salin token bot.
  2. Di PC gateway: Configurator → Aruni Gateway → tab Notifikasi, tempel token. Buka bot baru Anda di Telegram dan kirim /start.
  3. Klik Deteksi untuk mengisi Chat ID, klik Kirim tes, lalu Terapkan.

Peringatan yang tersedia: laptop jelajah offline lebih dari N jam (disertai kabar saat kembali online), percobaan akses ditolak, dan laptop baru mendaftar. Tambahkan bot ke grup Telegram agar seluruh tim IT ikut menerima.

3Riwayat

Catatan setiap laptop, siap Excel

  • Tab Riwayat mencatat kapan laptop online atau offline, di kantor atau di luar, siapa yang login, dan aplikasi apa yang sedang dibuka. Juga dicatat HP yang terhubung dan percobaan akses yang ditolak.
  • Pilih rentang waktu (24 jam, 7 hari, 30 hari, semua), lalu klik Ekspor ke Excel (CSV). File langsung terbuka rapi di Excel.
  • Lewat perintah: veyon-cli gateway activity laporan.csv 30.
4Tangkapan layar terjadwal

Bukti audit otomatis

  • Tab Laptop → Tangkapan layar terjadwal: pilih setiap 5, 10, 15, 30, atau 60 menit, lalu lama penyimpanannya (bawaan 30 hari).
  • Gambar tersimpan per laptop dan per tanggal di PC gateway. Klik Buka folder tangkapan layar untuk melihatnya.
  • PC gateway membutuhkan kunci autentikasi privat yang kunci publiknya terpasang di laptop (kunci yang sama dengan Master). Statusnya ditampilkan di tab tersebut.

Beri tahu pengguna laptop bahwa layar mereka dapat direkam berkala sesuai kebijakan kantor.

Baru di 1.5.0

Pengawasan yang lebih lengkap

Blokir situs per komputer, catatan siapa mengakses komputer mana, rekaman layar semua komputer dalam bentuk timelapse, siaran suara ke seluruh kelas, dan impor daftar komputer langsung dari Excel.

1Blokir situs

Situs terlarang, per komputer atau per ruangan

  • Di Master pilih komputer (atau satu ruangan), klik Blokir situs. Centang pilihan cepat (Media sosial, Video, Game online, Chat) atau ketik sendiri, satu situs per baris.
  • Klik Blokir. Blokir tetap berlaku setelah komputer dinyalakan ulang, sampai Anda klik Buka semua blokir.
  • Di aplikasi HP: menu Aksi → Blokir situs.

Windows: langsung berlaku, dan fitur DNS aman di Chrome, Edge, dan Firefox dimatikan agar tidak bisa diakali. Mac: pengguna Mac akan dimintai password administrator sekali setiap daftar berubah. VPN pribadi di komputer pengguna dapat menembus blokir ini.

2Log akses

Siapa mengakses komputer mana, kapan

  • Setiap komputer mencatat Master atau HP yang tersambung (alamat dan pengguna), berapa lama, fungsi yang dipakai (kunci layar, kendalikan, kirim file, matikan, …), serta percobaan akses yang gagal atau ditolak.
  • Di Master: pilih komputer → Log akses, lalu ekspor ke Excel. Di HP: menu komputer → Log akses.
  • Di PC gateway: tab Riwayat mengumpulkan log akses semua komputer setiap 15 menit, jadi bisa dilihat dan diekspor dari satu tempat. Kunjungan otomatis gateway sendiri tidak ikut dicatat di sana.
3Rekaman timelapse

Rekam layar semua komputer, putar per hari

  • Aruni Gateway → tab Laptop → Tangkapan layar terjadwal: pilih interval (5–60 menit) dan centang Semua komputer kantor.
  • Tab Rekaman: pilih komputer dan hari, lalu klik Putar. Kecepatan bisa diatur, dan slider bisa digeser ke jam tertentu.
  • Untuk merekam video penuh saat itu juga, pakai tombol Record screen di Master.
4Siaran suara

Bicara ke seluruh kelas sekaligus

  • Pilih komputer (atau semua), klik Siaran suara, lalu tahan tombol untuk bicara. Suara terdengar di semua komputer terpilih, dan di layar mereka muncul pemberitahuan kecil "Guru sedang berbicara".
  • Dari HP: Aksi → Siaran suara. Untuk percakapan dua arah dengan satu pengguna, pakai Bicara (AruniVoice).
5Impor dari Excel

Daftar komputer tanpa mengetik satu per satu

  1. Buat tabel di Excel dengan kolom Ruangan | Nama | Alamat IP | MAC (MAC boleh kosong). Klik Templat… untuk contoh siap isi.
  2. Configurator → Lokasi & komputer → Impor dari berkas… (simpan Excel sebagai CSV), atau blok barisnya di Excel, tekan Ctrl+C, lalu klik Tempel dari Excel.
  3. Pilih Tambahkan atau Ganti semua, lalu klik Terapkan. Baris yang bermasalah dilaporkan, dan komputer yang sudah ada diperbarui tanpa dobel.

Ekspor… menyimpan daftar saat ini ke CSV. Di aplikasi HP: Pengaturan → Ruangan & komputer → ikon impor.

Baru di 1.6.0 “Gita”

Pasang sekali jadi, jalan otomatis, ujian sekali klik

Satu kode untuk menyiapkan semua komputer, jadwal yang menyalakan, mengunci, dan mematikan komputer sendiri, serta mode ujian yang mengunci komputer untuk CBT dengan satu klik.

1Kode pemasangan

Satu kode untuk semua komputer, tanpa impor kunci satu per satu

  1. Di komputer admin: Configurator → Aruni Gateway → tab Pemasangan. Centang kunci yang dipakai, dan jika perlu daftar ruangan & komputer serta laptop jelajah. Klik Buat kode.
  2. Klik Simpan sebagai aruni-setup.txt… dan letakkan file itu di samping AruniControl-Setup-….exe (flashdisk atau folder bersama di jaringan).
  3. Jalankan installer di setiap komputer, bisa senyap: AruniControl-Setup-….exe /S. Kunci, metode autentikasi, dan pengaturan lainnya langsung terpasang. Untuk kode pendek bisa juga /S /SETUP=ARUNISETUP1:….

Mac: tempel kode di tab yang sama (bagian Siapkan komputer ini dengan kode), atau jalankan veyon-cli gateway setup kode. Kunci privat hanya disertakan untuk komputer guru/Master. Kode yang berisi kunci privat harus dirahasiakan.

2Jadwal otomatis

Komputer menyala, terkunci, dan mati sendiri

  • Configurator → Aruni Gateway → tab Jadwal → Tambah. Pilih aksi, jam, hari, dan ruangan (atau semua komputer). Klik Tambah contoh untuk jadwal siap pakai: nyala 07:00, kunci layar 12:00–13:00, mati 17:00.
  • Aksi yang tersedia: nyalakan (Wake-on-LAN), matikan (pengguna diberi peringatan 2 menit), mulai ulang, kunci/buka layar, blokir/buka internet, blokir/buka situs, kirim pesan, mulai/akhiri mode ujian.
  • Jalankan sekarang untuk mencoba. Hasil setiap jadwal (mis. “29 dari 30 komputer, tidak terjangkau: PC-07”) tampil di daftar, di tab Riwayat, dan di Telegram jika notifikasi diaktifkan.

Jadwal dijalankan oleh komputer admin itu sendiri, jadi komputer ini harus tetap menyala dan memiliki kunci autentikasi privat. Agar bisa dinyalakan otomatis, Wake-on-LAN harus aktif di BIOS dan alamat MAC tercatat di daftar komputer. Jadwal yang terlewat lebih dari 10 menit (misalnya karena komputer admin mati) tidak dijalankan belakangan.

3Mode ujian

Kunci komputer untuk ujian CBT dengan satu klik

  • Di Master pilih ruangan/komputer, lalu klik Mode ujian. Isi situs ujian (satu per baris) dan, jika perlu, alamat yang langsung dibuka di komputer siswa. Klik Mulai ujian. Dari HP: Aksi → Mode ujian.
  • Selama ujian: internet hanya bisa ke situs ujian, aplikasi chat, video call, remote, dan game (WhatsApp, Telegram, Discord, Zoom, AnyDesk, TeamViewer, Steam, …) ditutup dan tetap tertutup, serta tombol Windows, Alt+Tab, Alt+F4, Ctrl+Esc, dan Task Manager dikunci.
  • Klik tombol yang sama (Akhiri mode ujian) untuk mengembalikan semuanya. Mode ujian tetap aktif walaupun komputer dinyalakan ulang, dan bisa dijadwalkan (mis. Rabu 08:00–10:00).

Jika situs ujian memuat file dari alamat lain (mis. fonts.googleapis.com atau CDN), tambahkan juga alamat itu. Jaringan kantor selalu tetap bisa diakses. Mac: pengguna diminta memasukkan password administrator untuk memblokir internet. Ctrl+Alt+Del tidak bisa dikunci oleh aplikasi apa pun, tetapi Task Manager tetap terkunci.

Bantuan

Masalah yang sering ditemui

Komputer tidak muncul di Master / aplikasi

Pastikan layanan AruniControl berjalan di komputer tersebut (Configurator → Service → Running) dan komputer ada di jaringan yang sama. Firewall harus mengizinkan port TCP 11100. Installer Windows sudah menambahkan aturan ini otomatis.

Jika komputer berada di subnet lain, tambahkan manual lewat Configurator → Locations & computers, atau di aplikasi HP → Pengaturan → Ruangan & komputer.

Muncul “Kunci akses ditolak” / “Authentication failed”

Kunci di Master/HP tidak cocok dengan kunci publik di komputer tersebut. Periksa bahwa nama kunci sama persis di kedua sisi dan kunci publik sudah di-Import di komputer itu. Setelah mengubah kunci, klik Apply.

Mac: layar hitam, atau bisa lihat tapi tidak bisa diklik

macOS mewajibkan dua izin untuk veyon-server: Screen Recording (agar layar terlihat) dan Accessibility (agar klik/ketikan masuk). Tambahkan keduanya di System Settings → Privacy & Security, lalu restart layanan (Configurator → Service → Stop, lalu Start).

Windows: “Windows protected your PC”

Peringatan SmartScreen muncul karena installer belum memakai sertifikat tanda tangan berbayar. Klik More info → Run anyway. Anda bisa memastikan file asli dengan mencocokkan checksum SHA-256.

Android: “Aplikasi tidak terinstal” atau diblokir

Izinkan instalasi dari browser/file manager yang dipakai (Instal aplikasi tidak dikenal). APK ini untuk HP 64-bit (ARM64) dengan Android 9 ke atas. Jika sebelumnya ada versi lain dengan tanda tangan berbeda, hapus dulu versi lama.

Aruni Gateway “offline”

PC gateway harus menyala dan terhubung internet, dan layanan AruniControl harus berjalan di sana. Buka Configurator → Aruni Gateway dan pastikan status Online. Di HP, buka Akses dari mana saja → ⋮ → Sambungkan ulang. Jika gateway dipasang ulang, pindai kode QR yang baru.

Tampilan patah-patah saat lewat paket data

Lewat internet, gambar otomatis dikompres ke kualitas sedang agar hemat kuota (sekitar 35 KB/detik per layar yang dibuka). Thumbnail grid diperbarui lebih jarang. Untuk kontrol yang lebih lancar, buka satu komputer saja dalam mode layar penuh.

Laptop di rumah tidak muncul

Cek di laptop: Configurator → Aruni Gateway → status This laptop outside the office.

  • "The office gateway is offline": PC gateway kantor mati atau tidak terhubung internet.
  • "The office gateway refused this laptop": laptop sudah dihapus dari daftar, atau kode diganti sebelum laptop sempat terdaftar. Masukkan kode terbaru dari gateway.
  • Laptop harus menyala dan terhubung internet, dan layanan AruniControl harus berjalan (Configurator → Service).

Di Master kantor, laptop hanya muncul otomatis bila backend direktori adalah Network discovery dan port 11601–11699 di PC gateway tidak diblokir firewall. Installer Windows versi 1.3.1 sudah membukanya.

Port apa saja yang dipakai?
PortFungsi
11100 TCPKoneksi Master → komputer (wajib dibuka di firewall)
11200 TCPServer layar internal (hanya lokal)
11300 TCPFitur internal (hanya lokal)
11601–11698 TCPDi PC gateway: penerusan ke laptop jelajah (satu port per laptop)
11699 TCPDi PC gateway: daftar laptop jelajah untuk Master di kantor
